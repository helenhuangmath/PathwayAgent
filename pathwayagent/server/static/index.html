Background & advanced options

Input formats are detected automatically

Gene list

One gene per line. Runs the over-representation tools (Local ORA, Enrichr, g:Profiler, Reactome, STRING, clusterProfiler, ReactomePA, Metascape).

Ranked list

Two columns, gene and score (for example a Wald statistic). Adds the rank-based tools: mHG, pre-ranked GSEA, Wilcoxon, fgsea, g:Profiler ordered.

DE table

Columns gene, log2FoldChange, pvalue. Genes are ranked by signed −log10 p.

Several lists

Several columns under a header row, one list per column. The header is recognised by a header word (gene, module, cluster, list, set, up, down) or by names on a shared stem such as TEX_G1, TEX_G2.

Reading the results

Terms are matched across tools and scored 0–100. ROBUST terms are significant in at least two tools and two method families; SUPPORTED terms in at least two tools; SINGLE-TOOL terms in one. Terms are grouped into themes by shared hit genes, and key genes are ranked by their weight across themes.

Command line: python -m pathwayagent run genes.txt · REST: POST /api/v1/jobs (interactive API docs).

PathwayAgent

PathwayAgent runs several pathway-enrichment tools at once (local hypergeometric and rank tests, Enrichr, g:Profiler, Reactome, STRING, clusterProfiler, ReactomePA, fgsea, and Metascape result packages) on GO, KEGG, Reactome, WikiPathways, MSigDB Hallmark and DisGeNET, and combines them into a cross-tool consensus: robust themes, key genes and publication-ready figures.
