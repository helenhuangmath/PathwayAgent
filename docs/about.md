# Citation, license, contact

## Citation

If PathwayAgent contributes to a publication, please cite it:

> Huang H. PathwayAgent: fast multi-tool pathway analysis with cross-tool consensus. Version 1.0.1, 2026.
> <https://github.com/helenhuangmath/PathwayAgent>

Machine-readable metadata is in
[`CITATION.cff`](https://github.com/helenhuangmath/PathwayAgent/blob/main/CITATION.cff).

PathwayAgent builds on other tools and databases. Please cite the ones your run used as well:
`methods.txt` in every run folder gives a ready-made methods paragraph with their versions and
citations.
