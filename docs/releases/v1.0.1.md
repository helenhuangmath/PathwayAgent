# PathwayAgent v1.0.1

Published release version: **v1.0.1**.

Package metadata, runtime version, citation, Python API reference, installation examples,
and release commands now consistently use 1.0.1. This is a regular GitHub release.

PathwayAgent provides multi-tool pathway enrichment, cross-tool consensus scoring, themes,
key genes, HTML/Excel reports, figures, a command-line interface, and a local web app with REST API.

## Downloads and installation

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install ./pathwayagent-1.0.1-py3-none-any.whl
export PATHWAYAGENT_LIBRARY="$PWD/library"
export PATHWAYAGENT_RESULTS="$PWD/results"
.venv/bin/python -m pathwayagent db build --organism mmusculus
.venv/bin/python -m pathwayagent.examples.interferon --out results/interferon
```

See the [Python API reference](https://github.com/helenhuangmath/PathwayAgent/blob/v1.0.1/docs/PYTHON_API.md)
and [worked example](https://github.com/helenhuangmath/PathwayAgent/blob/v1.0.1/docs/WORKED_EXAMPLE.md).
The example uses local Hallmark over-representation analysis on illustrative mouse interferon genes;
its significant results are labeled SINGLE-TOOL evidence.

## Verification and limitations

The release is checked with the offline suite, lint, distribution metadata checks, and an installed-wheel
smoke test covering enrichment, HTML/PDF/Excel output, API health, and bundled assets. The example
outputs are generated with the installed wheel and existing mouse reference library.

External-service live tests and a fresh database download are not included in this verification.
R-based tools require a separate R/Bioconductor installation. WebGestalt, DAVID, and GREAT remain
planned; the local web server stores jobs in memory. This release does not publish to PyPI or change
repository visibility.
