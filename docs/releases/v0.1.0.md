# PathwayAgent v0.1.0 (alpha)

> Historical preparation notes for the earlier v0.1.0 tag. A GitHub release was not published for
> this version. The current formal release is
> [v1.0.1](https://github.com/helenhuangmath/PathwayAgent/releases/tag/v1.0.1).

First packaged release of PathwayAgent: multi-tool pathway enrichment, cross-tool consensus,
themes, key genes, publication figures, HTML/Excel reports, a CLI, and a local web app with REST API.

This release adds verified repository links, a Python API reference, a small example shipped inside
the package, modern MIT license metadata, and installation/report smoke checks in CI. It also fixes
installation instructions that referred to an undefined `llm` extra.

## Downloads

- `pathwayagent-0.1.0-py3-none-any.whl`: installable Python wheel.
- `pathwayagent-0.1.0.tar.gz`: source distribution, including API documentation and test inputs.
- `interferon-example-v0.1.0.zip`: worked-example report, tables, workbook, and figures.
- `SHA256SUMS`: SHA-256 checksums for the three assets above.

Python 3.11 or newer is required. This GitHub release does not publish the package to PyPI.

## Small worked example

After downloading the wheel, create a virtual environment and install it:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install ./pathwayagent-0.1.0-py3-none-any.whl
export PATHWAYAGENT_LIBRARY="$PWD/library"
export PATHWAYAGENT_RESULTS="$PWD/results"
.venv/bin/python -m pathwayagent db build --organism mmusculus
.venv/bin/python -m pathwayagent.examples.interferon --out results/interferon
```

Open `results/interferon/report.html`. The example uses 20 illustrative mouse genes and local
Hallmark over-representation analysis. After database setup, it needs neither R nor web services.
With the release-verification library (MSigDB 2026.1.Mm), interferon α and γ response were the top
two terms, both with adjusted p = 3.64 × 10⁻¹⁹. Evidence is correctly labeled SINGLE-TOOL.

See the [worked example](https://github.com/helenhuangmath/PathwayAgent/blob/v0.1.0/docs/WORKED_EXAMPLE.md)
and [Python API reference](https://github.com/helenhuangmath/PathwayAgent/blob/v0.1.0/docs/PYTHON_API.md).

## Verification

- All 20 offline tests passed locally on Python 3.12 with the compiled mouse reference library,
  including planted-signal, null-calibration, and R/clusterProfiler agreement checks.
- Ruff lint and `pip check` passed; wheel and source metadata passed `twine check`.
- Wheel and source archive installed in separate fresh Python environments on macOS.
- Installed-package smoke checks exercise synthetic enrichment, HTML/PDF/Excel output,
  API health, static examples, version agreement, and the bundled R worker.
- The packaged interferon example ran successfully from the installed wheel outside the checkout.

## Limitations

Alpha research software: validate findings before relying on them. External-service live tests
and a fresh reference-library download were not exercised for this release. R adapters require
an additional R/Bioconductor installation. WebGestalt, DAVID, and GREAT remain planned.
Reference-library-dependent tests skip explicitly in clean checkouts without a compiled library;
CI separately checks reporting against synthetic data. The local server stores jobs in memory.
